## 基本步骤
> 研发人员无组织功能模块，无法添加账户；无法产品发布
- 添加账号 （无）
- 创建产品
- 创建需求
- 创建项目、关联产品、设置团队
- 关联需求
- 分解任务
- 创建Bug
- 提交测试
- 创建发布 （无）

## 创建项目
点击项目页面 → 添加项目  
![[禅道项目管理系列教程-7.png]]
填写项目信息创建
![[禅道项目管理系列教程-8.png]]

## 设置团队
项目 → 团队 → 点击团队管理
![[禅道项目管理系列教程-9.png]]
添加团队成员，设置队员角色等信息保存创建
![[禅道项目管理系列教程-10.png]]

## 关联需求
项目 → 选择产品 → 关联产品需求 → 保存
![[禅道项目管理系列教程-11.png]]
关联完成后 → 点击项目 → 需求 → 查看关联后的需求列表
![[禅道项目管理系列教程-12.png]]

## 分解任务
项目 → 需求 → 点击批量拆分任务
![[禅道项目管理系列教程-13.png]]
将需求拆分成任务 → 编辑任务信息保存
![[禅道项目管理系列教程-14.png]]

## 指派任务
项目 → 任务 → 多选任务 → 编辑 
![[禅道项目管理系列教程-15.png]]
编辑任务的的负责人、优先级、预计工时等信息
![[禅道项目管理系列教程-16.png]]
