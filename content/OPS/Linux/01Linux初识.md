### Linux基本使用

#### 关机重启

- 关机 （now表示立刻关机）

```shell
shutdown -h now

#表示1分钟后关机
shutdown -h +1
```

- 重启

```shell
#立刻重启
shutdown -r now
#15分钟后重启
shutdown -r +15
#立刻重启
reboot
```

#### ls命令(查看目录)

- 基本使用

>在当前目录下输入ls命令可以查看该目录下的所有文件和目录，如下图是在根目录下输入ls命令，可以看到linux系统的目录

![](2023-07-17140911.png)

- 查看目标目录

>ls后面加路径可以查看目标目录下的文件

![](2023-07-17141413.png)

- 查看隐藏文件

>ls后面加 -a。在Linux系统中隐藏文件以点开头

![](2023-07-17141821.png)

- 查看详情

>ls后面跟 -l

![](2023-07-17142242.png)

- 其他操作

```shell
-a 显示所有文件及目录 (. 开头的隐藏文件也会列出)
-d 只列出目录（不递归列出目录内的文件）。
-l 以长格式显示文件和目录信息，包括权限、所有者、大小、创建时间等。
-r 倒序显示文件和目录。
-t 将按照修改时间排序，最新的文件在最前面。
-A 同 -a ，但不列出 "." (目前目录) 及 ".." (父目录)
-F 在列出的文件名称后加一符号；例如可执行档则加 "*", 目录则加 "/"
-R 递归显示目录中的所有文件和子目录。
```

#### cd命令(切换目录)

- 基本使用

```shell
#绝对路径写法，以/开头，从目录开始
cd /usr/bin
#指定录的路径来切换到目标目录相对于当前目
cd etc/
```

- 切换到上级目录

```shell
#切换到上一级
cd ..
#切换到上上级目录
cd ../../
```

- 切换到主目录(home)

```shell
cd ~
```
