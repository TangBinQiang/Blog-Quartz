# 小学单位换算题（答案）
## 一、长度单位
1. 5米 = **500**厘米
2. 3千米 = **3000**米
3. 70毫米 = **7**厘米
4. 2分米5厘米 = **25**厘米
5. 450厘米 = **4**米**50**厘米

## 二、重量单位
1. 2吨 = **2000**千克
2. 6千克 = **6000**克
3. 3000千克 = **3**吨
4. 1吨500千克 = **1500**千克
5. 4800克 = **4**千克**800**克

## 三、时间单位
1. 2时 = **120**分
2. 3分 = **180**秒
3. 120秒 = **2**分
4. 1时30分 = **90**分
5. 150分 = **2**时**30**分

## 四、面积单位
1. 1平方米 = **100**平方分米
2. 3平方分米 = **300**平方厘米
3. 500平方厘米 = **5**平方分米
4. 2平方米 = **20000**平方厘米

## 五、容积/人民币
1. 3升 = **3000**毫升
2. 5000毫升 = **5**升
3. 4元5角 = **45**角
4. 70分 = **7**角
