这里给你出一套**小学常用单位换算计算题**，涵盖长度、重量、时间、面积、容积，难度适中，适合练习：

# 一、长度单位（米、分米、厘米、毫米、千米）
1. 5米 = (    )厘米
2. 3千米 = (    )米
3. 70毫米 = (    )厘米
4. 2分米5厘米 = (    )厘米
5. 450厘米 = (    )米(    )厘米

# 二、重量单位（吨、千克、克）
1. 2吨 = (    )千克
2. 6千克 = (    )克
3. 3000千克 = (    )吨
4. 1吨500千克 = (    )千克
5. 4800克 = (    )千克(    )克

# 三、时间单位（时、分、秒）
1. 2时 = (    )分
2. 3分 = (    )秒
3. 120秒 = (    )分
4. 1时30分 = (    )分
5. 150分 = (    )时(    )分

# 四、面积单位（平方米、平方分米、平方厘米）

2. 3平方分米 = (    )平方厘米
3. 500平方厘米 = (    )平方分米
4. 2平方米 = (    )平方厘米
