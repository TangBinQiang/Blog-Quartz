# 谓语动词的及物属性决定了宾语形式，进而影响语义完整性

### 一、核心区别对比表

|        |                               |                                                          |
| ------ | ----------------------------- | -------------------------------------------------------- |
| 对比维度   | That jacket belongs to my son | She chose to live                                        |
| 句子结构   | 主谓宾结构（完整语义）                   | 主谓宾结构（语义不完整，需补充状语）                                       |
| 谓语构成类型 | 复合谓语（固定及物动词短语）                | 复合谓语（实义动词 + 不定式短语作宾语）                                    |
| 核心谓语成分 | belongs to（固定短语，表 “属于”，及物属性）  | chose（实义及物动词，表 “选择”，后接不定式作宾语）                            |
| 宾语情况   | 直接接名词短语 “my son” 作宾语，无需补充其他成分 | 接不定式短语 “to live” 作宾语，但 “live” 是不及物动词，需加地点状语（如 “here”）才完整 |
| 语义完整性  | 语义完整，明确 “夹克的归属”               | 语义残缺，仅说 “她选择居住”，未说明 “居住地点”                               |

### 二、具体拆解说明

#### 1. 谓语构成与功能差异

- 前者谓语 “belongs to” 是**固定及物动词短语**，整体充当谓语，必须直接接宾语（如 “my son”）才能表达完整意思，属于 “短语动词作谓语” 的复合谓语类型。

- 后者谓语 “chose” 是**单个及物动词**，后接不定式 “to live” 作宾语，构成 “动词 + 不定式” 的复合宾语结构，属于 “实义动词 + 宾语” 的简单谓语拓展形式。

#### 2. 宾语性质与语义逻辑差异

- “belongs to” 的宾语是**名词 / 代词**（如 “my son”），直接体现动作的承受者（归属对象），逻辑闭环，无需额外补充成分。

- “chose” 的宾语是**不定式短语 “to live”**，但 “live” 本身是不及物动词，无法单独体现 “居住” 的场景，必须补充地点状语（如 “to live in Beijing”），句子语义才完整。

#### 3. 动词属性延伸差异

- “belong to” 是**不可拆分的固定短语**，不能说 “belongs my son to”，宾语必须跟在短语后面，无被动语态（不能说 “is belonged to”）。

- “chose” 是**可接不定式作宾语的及物动词**，类似用法如 “decide to do”“want to do”，“to live” 作为不定式宾语，其后续是否需要补充成分，取决于不定式动词是否及物（此处 “live” 不及物，需补状语）。

### 补充总结

简单来说，前句是 “固定及物短语 + 名词宾语”，语义完整、结构闭环；后句是 “及物动词 + 不定式宾语”，因不定式动词为不及物，需补充状语才能让表意完整。两者的核心差异本质是 “谓语的短语属性” 与 “宾语的语义要求” 不同。
