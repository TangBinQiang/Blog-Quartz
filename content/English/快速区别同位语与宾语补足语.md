### 同位语与宾语补足语的核心区别

|              |                                                    |                                                          |
| ------------ | -------------------------------------------------- | -------------------------------------------------------- |
| 区分维度     | 同位语                                             | 宾语补足语                                               |
| **修饰对象** | 修饰**名词 / 代词**（与之指同一人 / 物，地位平等） | 修饰**宾语**（补充说明宾语的状态、身份等）               |
| **语法关系** | 与被修饰成分是**同位关系**（逻辑上 “等价”）        | 与宾语是**补充关系**（逻辑上 “宾语是宾补的主语 / 对象”） |
| **结构形式** | 常以**逗号隔开**，或由 that、whether 等引导        | 紧跟宾语，无逗号，常见结构 “动词 + 宾语 + 宾补”          |
| **逻辑关系** | 同位语可**替换**被修饰成分（语义不变）             | 宾补**不能替换**宾语（是对宾语的补充说明）               |

### 示例对比

- **同位语**：_We all like our monitor, Tom._（“Tom” 是 “monitor” 的同位语，两者指同一人，可替换）

- **宾语补足语**：_We made him our leader._（“our leader” 是宾补，补充说明 “him” 的身份，“him” 是 “our leader” 的逻辑主语，不可替换）

### 关键总结

- 同位语是 “**等价说明**”，和被修饰成分 “平起平坐”；

- 宾语补足语是 “**补充延伸**”，让宾语的意思 “更完整具体”。
