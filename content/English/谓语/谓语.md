### 谓语的定义与核心特征

谓语是句子中**表示动作或状态**的核心成分，通常由**动词或动词短语**担任，用来连接主语和句子的其他成分（如宾语、表语等），体现句子的核心表意逻辑。

### 谓语的构成类型

|                     |                                 |                                                                                                                             |
| ------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 类型                | 示例                            | 说明                                                                                                                        |
| 简单谓语            | 单个动词（含系动词、实义动词）  | He **runs** every day.（实义动词，表动作）She **is** a teacher.（系动词，表状态）                                           |
| 复合谓语            | 动词短语（固定搭配 / 时态结构） | They **are looking for** their dog.（现在进行时，“be+doing” 结构）That jacket **belongs to** my son.（固定短语，表 “属于”） |
| 情态动词 + 动词原形 | 表能力、推测等情态语义          | We **can speak** English.（“can+speak”，表能力）You **should finish** the task.（“should+finish”，表建议）                  |

### 关键补充

- 谓语的 “核心性”：一个句子只能有一个谓语（除非是并列句，如 “He sings and dances.” 中 “sings” 和 “dances” 并列作谓语）。

- 与主语的 “数一致”：谓语动词的形式需和主语的单复数、人称匹配（如主语是第三人称单数时，实义动词需加 “-s/-es”，如 “He **runs**.”）。
