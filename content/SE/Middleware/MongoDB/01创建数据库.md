# MongoDB 数据库创建笔记

## 一、核心概念

MongoDB 是 NoSQL 数据库，数据以文档BSON（类型JSON 格式）存储。

| 概念 | MongoDB | MySQL |
|------|---------|-------|
| 数据库 | Database | Database |
| 表 | Collection（集合） | Table |
| 行 | Document（文档） | Row |
| 列 | Field（字段） | Column |

集合与表的区别：表需要提前定义列结构，集合不需要，直接插入数据即可。

---

## 二、连接数据库

直接使用Mongo Campass可视化管理软件链接

```bash
mongosh
```

连接成功后终端显示 `test>` 提示符即可开始操作。

---

## 三、创建数据库

```javascript
use 数据库名称
```

注意：`use` 只是切换，不会立即创建。必须插入数据后数据库才真正存在。

```javascript
use myshop
db.users.insertOne({ name: "张三", age: 18 })
// users 是集合名，不存在时会自动创建
```

---

## 四、查看与删除

```javascript
show dbs            // 查看所有数据库
db                  // 查看当前数据库
show collections    // 查看当前库的所有集合
db.dropDatabase()   // 删除当前数据库
```

注意：`admin`、`config`、`local` 是系统数据库，不要删除。

---

## 五、命名规范

- 只能使用字母、数字、下划线、连字符
- 区分大小写，`mydb` 和 `MyDB` 是两个不同的数据库
- 不能包含空格、`.`、`/`、`\`
- 避免使用系统保留名：`admin`、`local`、`config`

---

## 六、完整操作流程

```javascript
use game                                           // 创建并切换
db.players.insertOne({ name: "小明", score: 100 }) // 插入数据使数据库生效
show dbs                                           // 验证已创建
show collections                                   // 查看集合
db.dropDatabase()                                  // 删除数据库
```

---

## 七、常见问题

**Q：use 后 show dbs 看不到新数据库？**
A：必须先插入一条数据，数据库才会正式创建。

**Q：怎么知道当前在哪个数据库？**
A：输入 `db` 即可显示当前数据库名称。

**Q：use 切换数据库后原数据库的数据会丢失吗？**
A：不会，数据一直保存在原数据库中，随时可以 `use` 切换回去。
