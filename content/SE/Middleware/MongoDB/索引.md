## MongoDB 索引

---

## 一、什么是索引

索引是一种数据结构，帮助 MongoDB 快速定位数据，不用扫描整个集合。

类比：书的目录就是索引，通过目录可以直接翻到对应页，而不用从第一页一页翻。

---

## 二、查看索引

```js
db.users.getIndexes()
```

MongoDB 默认会给每个集合的 `_id` 字段创建索引。

---

## 三、创建索引

```js
// 单字段索引
db.users.createIndex({ age: 1 })   // 1 升序，-1 降序

// 复合索引（多个字段）
db.users.createIndex({ age: 1, name: -1 })

// 唯一索引（该字段不允许重复值）
db.users.createIndex({ email: 1 }, { unique: true })

// 给索引命名
db.users.createIndex({ age: 1 }, { name: "idx_age" })
```

---

## 四、删除索引

```js
// 删除指定索引
db.users.dropIndex("idx_age")

// 删除所有索引（_id 索引除外）
db.users.dropIndexes()
```

---

## 五、分析查询是否用到索引

```js
db.users.find({ age: { $gt: 18 } }).explain("executionStats")
```

重点关注输出中的两个字段：

| 字段 | 含义 |
|------|------|
| `winningPlan.stage: "IXSCAN"` | 使用了索引，性能好 |
| `winningPlan.stage: "COLLSCAN"` | 全表扫描，没用到索引，性能差 |

---

## 六、常见索引类型

| 类型 | 说明 |
|------|------|
| 单字段索引 | 对一个字段建立索引 |
| 复合索引 | 对多个字段联合建立索引 |
| 唯一索引 | 字段值不允许重复 |
| 文本索引 | 用于全文搜索 |
| TTL 索引 | 文档到期后自动删除 |

---

## 七、TTL 索引示例

```js
// 文档在 createdAt 时间的 3600 秒（1小时）后自动删除
db.logs.createIndex({ createdAt: 1 }, { expireAfterSeconds: 3600 })
```

常用于日志、验证码、session 等有时效性的数据。

---

## 八、复合索引注意事项

复合索引遵循**最左前缀原则**，即查询条件必须包含索引的第一个字段才能命中索引。

```js
// 创建复合索引
db.users.createIndex({ age: 1, name: 1 })

// 能命中索引
db.users.find({ age: 18 })
db.users.find({ age: 18, name: "张三" })

// 不能命中索引
db.users.find({ name: "张三" })
```

---

## 九、常见问题

**Q：索引越多越好吗？**
A：不是。索引会占用额外存储空间，且每次插入、修改、删除数据时都需要同步更新索引，索引过多会影响写入性能。建议只对频繁查询的字段建立索引。

**Q：什么时候不需要索引？**
A：数据量很小时，全表扫描速度已经足够快，索引反而增加开销。
